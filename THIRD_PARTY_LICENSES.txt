노애드플레이어(NoAdPlayer)가 사용하는 오픈소스 구성요소
=====================================================

이 프로그램은 아래 라이브러리를 수정 없이 동적 링크(별도 DLL·파이썬 패키지)로 사용합니다.
LGPL 구성요소는 사용자가 같은 인터페이스의 다른 버전으로 교체할 수 있습니다
(앱 폴더의 해당 DLL·패키지를 바꾸면 됩니다). 소스 코드는 아래 주소에서 받을 수 있습니다.

[재생 엔진]
- mpv (libmpv-2.dll) — LGPL-2.1-or-later 빌드
  소스: https://github.com/mpv-player/mpv
  빌드: https://github.com/zhongfly/mpv-winbuild (mpv-dev-lgpl-x86_64)
- FFmpeg (libmpv 내장, 처음 쓸 때 받는 추가 기능 ffmpeg.exe) — LGPL-2.1-or-later 빌드 (GPL 구성요소 미포함)
  소스: https://ffmpeg.org/download.html
  빌드: https://github.com/BtbN/FFmpeg-Builds (win64-lgpl)

[화면]
- Qt for Python (PySide6, shiboken6) — LGPL-3.0
  소스: https://code.qt.io/cgit/pyside/pyside-setup.git
- python-mpv — LGPL-2.1-or-later (GPL/LGPL 이중 라이선스 중 LGPL 선택)
  소스: https://github.com/jaseg/python-mpv

[AI 자막] (설치 파일에 넣지 않고, 처음 쓸 때 '추가 기능'으로 내려받음)
- faster-whisper — MIT — https://github.com/SYSTRAN/faster-whisper
- CTranslate2 — MIT — https://github.com/OpenNMT/CTranslate2
- ONNX Runtime — MIT — https://github.com/microsoft/onnxruntime
- tokenizers, huggingface_hub — Apache-2.0 — https://github.com/huggingface
- NumPy — BSD-3-Clause — https://numpy.org
- Whisper large-v3-turbo 모델 — MIT (OpenAI), CTranslate2 변환본: mobiuslabsgmbh/faster-whisper-large-v3-turbo
  (첫 사용 때 Hugging Face 에서 내려받음)
- NVIDIA cuBLAS — NVIDIA 소프트웨어 라이선스 (설치본에 포함하지 않음. NVIDIA GPU 가 있는 PC 에서
  AI 자막 첫 사용 때 PyPI 의 nvidia-cublas-cu12 배포본을 받아 씀)

[자막 번역]
- llama.cpp (추가 기능 'llama', Vulkan 빌드) — MIT — https://github.com/ggml-org/llama.cpp
  (포함된 LLVM OpenMP 런타임 libomp.dll — Apache-2.0 WITH LLVM-exception, LICENSE-LLVM-OpenMP 참고)
- Tencent Hy-MT2-1.8B 번역 모델 (GGUF Q4_K_M) — Apache-2.0 — https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF
  (첫 사용 때 Hugging Face 에서 내려받음)
- DeepL·Google Cloud Translation·Microsoft Translator — 사용자가 본인 계정 API 키를 넣었을 때만 사용하며,
  이용 조건과 요금은 사용자와 각 회사 사이의 약관을 따릅니다.

[소리 인코더 — ffmpeg.exe 내장]
- LAME (MP3) — LGPL-2.0-or-later, FLAC — BSD-3-Clause

각 라이선스 전문은 위 소스 주소의 저장소에 있습니다.
